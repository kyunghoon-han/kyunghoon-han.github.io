# KH's Personal Site

A Windows 98-style personal homepage. Drop markdown files into `writings/`,
run one command, reload. MathJax renders the math; the desktop and Start
menu work even without a server.

## Quick start

```
python3 build.py        # scans writings/, generates content.js
python3 -m http.server  # then open http://localhost:8000
```

Or in one go:

```
python3 build.py serve
```

## Adding an article

1. Drop a markdown file anywhere under `writings/`. Suggested layout:
   `writings/<year>/<YYYY-MM-DD>-<slug>.markdown`.
2. Put Jekyll-style frontmatter at the top:
   ```
   ---
   title : "Adjoint methods for finding a set of periodic orbits"
   subtitle : "A theoretical consideration"
   categories : mathematics
   tags : analysis chaos
   ---
   ```
3. Run `python3 build.py`. The script reads the frontmatter, derives the
   date from the filename (or a `date:` field), and regenerates
   `content.js`.
4. Reload the page.

The Notebook tree (and the Start menu cascade) is built automatically by
**year → month → article**, newest first.

### What the build script reads

From each markdown file's frontmatter:

| Field        | Used for                                        |
|--------------|-------------------------------------------------|
| `title`      | Article title (falls back to the filename stem) |
| `subtitle`   | Subtitle shown under the title                  |
| `date`       | Year/month grouping (falls back to filename)    |
| `categories` | Shown in the article header                     |
| `tags`       | Shown in the article header                     |

Anything else in the frontmatter (`layout`, `comments`, `usemathjax`, etc.)
is ignored.

### Math

`$$...$$` and `$...$` both work. Detection:

- `$$...$$` **alone on its own line** → display math (centered, own block)
- `$$...$$` **mid-paragraph** → inline math
- `$...$` → inline math

MathJax handles essentially all standard LaTeX out of the box —
`\begin{eqnarray}`, `\mathbf`, `\mathcal`, `\mmlToken`, custom environments,
the works. No KaTeX preprocessing or substitution.

## Personal links

Edit the top of `script.js`:

```js
const CONFIG = {
  email:    'you@example.com',
  scholar:  'https://scholar.google.com/citations?user=YOUR_ID',
  github:   'https://github.com/...',
  linkedin: 'https://www.linkedin.com/in/YOUR_HANDLE',
  cv:       'cv.pdf'
};
```

Drop your CV into the project as `cv.pdf` (or change the path).

## Visualizations

The Visualizations list lives at the top of `build.py`:

```python
VISUALIZATIONS = [
    {"title": "Wobble",            "src": "https://kyunghoon-han.github.io/wobble.html"},
    {"title": "FIMD Sonification", "src": "https://kyunghoon-han.github.io/FIMD_sonification.html"},
]
```

Edit and re-run `python3 build.py`.

## Avatar, wallpaper, favicon

- `me.png` — Start-menu avatar (clipped to a circle)
- `background.png` — desktop wallpaper
- `favicon.ico` — browser tab icon

## Caveats

- **MathJax loads from CDN** (jsdelivr). First article render may have a
  brief pause while it finishes loading; subsequent ones are instant.
- **iframes** need the embedded page to allow framing. `github.io` pages
  work; Google/YouTube refuse via `X-Frame-Options`.
- **Mobile**: windows fullscreen, drag/resize disabled, double-tap to open.
  Cascading Start menu collapses to direct folder-open.
